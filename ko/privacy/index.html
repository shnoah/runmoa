RunMoa 개인정보처리방침

최종 업데이트: 2026년 7월 10일

RunMoa는 Apple 건강에 저장된 러닝 기록을 iPhone에서 러너 중심으로 정리해 보여주는 앱입니다.

개요

계정 생성은 필요하지 않습니다. 광고나 소셜 추적 기능을 포함하지 않으며 Apple 건강 러닝 기록, 경로, 심박 샘플, 러닝 메모, 신발 데이터, 선택한 사진과 완성 이미지를 개발자 서버로 업로드하지 않습니다.

TestFlight와 App Store 배포 빌드에서는 Firebase Analytics와 Crashlytics를 사용합니다. 이 서비스는 식별자, 제품 상호 작용, 크래시·성능·기기·운영체제·앱 버전과 진단 메타데이터를 수집할 수 있습니다. RunMoa는 Apple 건강 세부 정보, 경로, 심박 샘플, 메모, 신발 데이터, 사진 또는 사용자 ID를 Firebase 보고서에 직접 첨부하지 않습니다.

읽는 건강 데이터

  • 러닝 워크아웃과 경로
  • 심박수와 안정시 심박수
  • VO₂ Max
  • 걷기/달리기 거리와 걸음 수
  • 러닝 속도와 보폭
  • 지원되는 시스템의 운동 노력 데이터

이 데이터는 iPhone 안에서 러닝 요약, 러닝 컨디션, 심박 존, 상세 차트, 개인 기록, 신발 연결과 공유 이미지 표시를 만드는 데 사용됩니다.

기기 안에 저장되는 데이터

앱 설정, 심박 존 설정, 신발 정보·표시 순서·러닝 연결, 러닝 메모, 개인 기록 검토 결과와 파생 요약·차트 캐시는 파일 보호를 적용한 앱 컨테이너에 저장하고 자동 iCloud/Finder 백업 대상에서 제외합니다.

스티커 편집용 사진

iOS 시스템 사진 선택기가 사용자가 고른 사진만 전달합니다. 사진과 스티커 합성은 기기 안에서 처리하며 업로드하지 않습니다. 사진 추가 권한은 완성 이미지를 저장할 때만 요청합니다.

사용자가 직접 내보내는 데이터

생성한 이미지나 개인 백업 JSON을 복사·저장·공유하기로 직접 선택한 경우에만 외부로 전달하며 Apple 건강 원본과 상세 샘플은 백업에 포함하지 않습니다.

사용자 제어

  • iOS 설정에서 Apple 건강 접근을 변경할 수 있습니다.
  • RunMoa 설정에서 신발 데이터와 분석 캐시를 삭제할 수 있습니다.
  • 개인 백업을 내보내거나 가져올 수 있습니다.
  • 앱 삭제 시 앱 내부 데이터도 제거됩니다.
