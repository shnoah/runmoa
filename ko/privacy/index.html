RunMoa 개인정보처리방침

시행일: 2026년 11월 8일

RunMoa는 Apple 건강에 저장된 러닝 기록을 iPhone에서 러너 중심으로 정리해 보여주는 앱입니다.

2026년 11월 8일 개정: RunMoa 1.3.0부터 제공하는 선택 기능인 Garmin 직접 연동에 맞춰 Garmin 데이터의 항목·목적·보관·국외 처리·이용자 권리와 운영 진단 안내를 현재 운영 기준으로 고치고, 사용자가 직접 실행하는 iCloud·파일 백업에 Garmin 기록이 포함되는 점을 추가했습니다.

2026년 10월 29일 개정: 운영자·문의 연락처, 선택형 iCloud 백업, Garmin 연동 운영 원칙과 서비스 제공업체 안내를 추가·명확화했습니다.

개요

계정 생성은 필요하지 않습니다. Apple 건강 러닝 기록, 경로, 심박 샘플, 러닝 메모, 신발 데이터, 선택한 사진과 완성 이미지를 개발자 서버로 업로드하지 않습니다. 선택 기능인 Garmin 직접 연동을 사용하면 Garmin 운동이 아래 Garmin 절에 설명한 서버를 거쳐 iPhone으로 전달됩니다.

배포 빌드에서는 Firebase Analytics와 Crashlytics로 사용 통계와 진단 정보를 처리합니다. 러닝 상세와 스티커 편집 화면에는 Google AdMob 배너 광고가 표시됩니다.

광고 및 추적

Google Mobile Ads와 User Messaging Platform은 광고 제공·측정과 분석을 위해 IP 주소에서 추정한 대략적 위치, 기기 식별자, 광고 데이터, 제품 상호 작용, 충돌·성능·기타 진단 정보를 처리할 수 있습니다.

필요한 경우 광고를 요청하기 전에 Google 동의 메시지와 Apple 앱 추적 투명성 권한을 표시합니다. 개인화 광고와 추적을 허용하면 광고 식별자를 이용해 다른 앱과 웹사이트의 활동을 연결할 수 있습니다. 거부하면 허용되는 범위에서 비개인화 또는 제한 광고가 제공될 수 있습니다. 더보기 > 데이터 관리와 iOS 설정에서 선택을 변경할 수 있습니다.

Apple 건강 운동, 경로 좌표, 심박, 페이스, 케이던스, 고도, 메모, 신발과 사진은 광고 요청에 포함하거나 광고·타게팅에 사용하지 않습니다. Google Mobile Ads의 게시자 퍼스트 파티 식별자는 비활성화합니다.

읽는 건강 데이터

  • 러닝 워크아웃과 경로
  • 심박수와 안정시 심박수
  • VO₂ Max
  • 걷기/달리기 거리와 걸음 수
  • 러닝 속도와 보폭
  • 지원되는 시스템의 운동 노력 데이터

이 데이터는 아래 Apple 서비스 요청을 제외하면 iPhone 안에서 러닝 요약, 러닝 컨디션, 심박 존, 상세 차트, 개인 기록, 신발 연결과 공유 이미지 표시를 만드는 데 사용됩니다.

Apple 지도 및 날씨 서비스

Apple 건강 경로가 있는 실외 러닝은 첫 정상 경로 좌표와 시작 시각을 Apple 지도와 Apple 날씨 서비스에 전달해 간단한 위치명과 당시 시간별 날씨를 조회할 수 있습니다. 현재 위치 권한은 요청하지 않습니다. 경로, 조회 가능한 과거 날씨 또는 필수 Apple Weather 출처 정보가 없으면 날씨를 표시하지 않습니다.

조회 결과인 표시용 위치명과 날씨 값만 iPhone에 캐시합니다. 대표 좌표는 이 캐시에 저장하지 않으며 Firebase, Crashlytics, AdMob 또는 개발자 서버로 보내지 않습니다. Apple 서비스 요청은 Apple의 관련 개인정보 보호 조건에 따라 처리됩니다.

기기 안에 저장되는 데이터

앱 설정, 심박 존 설정, 신발 정보·표시 순서·러닝 연결, 러닝 메모, 개인 기록 검토 결과, 파생 요약·차트 캐시와 최대 100개의 표시용 위치·날씨 캐시는 파일 보호를 적용한 앱 컨테이너에 저장하고 자동 iCloud/Finder 백업 대상에서 제외합니다. 위치·날씨 캐시에 원본 경로 좌표는 저장하지 않습니다. 기기에 받은 Garmin 기록도 같은 방식으로 저장하며 자동 백업에서 제외합니다.

사용자가 실행하는 iCloud 개인 데이터 백업

지금 iCloud에 백업을 선택하면 신발 정보와 표시 순서, 러닝-신발 연결, 직접 작성한 러닝 메모, 월간·주간 목표 설정, 그리고 Garmin 직접 연동으로 받은 운동 기록(경로·심박 포함 원본)의 최신 스냅샷 1개를 사용자의 비공개 CloudKit database에 저장합니다. 더보기 > 데이터 관리 > 백업 및 복원에서 복원하고, 해당 화면의 iCloud 백업 관리에서 삭제할 수 있으며 자동·실시간 동기화는 하지 않습니다.

러닝 연결과 메모에는 HealthKit 운동 UUID 원문 대신 앱 전용 도메인으로 만든 단방향 불투명 참조값을 저장합니다. Apple 건강 운동 날짜, 거리, 시간, 경로, 심박, 페이스, sample, source, 개인 기록과 파생 분석 캐시는 포함하지 않습니다. 같은 식별자의 운동이 기기에 아직 없으면 날짜·거리·시간으로 추측하지 않고 연결과 메모를 로컬 pending 상태로 보관합니다.

백업은 사용자의 CloudKit private database에서 암호화된 asset으로 저장되며 개발자 운영 서버, Firebase, Crashlytics, Google Mobile Ads, 광고 또는 분석 서비스로 전달되지 않습니다.

사진과 내보내기

iOS 시스템 사진 선택기는 사용자가 고른 사진만 전달합니다. 사진과 스티커 합성은 기기 안에서 처리합니다. 완성 이미지를 저장할 때만 사진 추가 권한을 요청하며, 이미지와 개인 백업 JSON은 사용자가 직접 복사·저장·공유할 때만 외부로 전달됩니다.

detailMapCard는 기본적으로 경로의 처음과 마지막 200m를 숨깁니다. 현재 편집 세션에서 전체 경로를 선택할 수 있으며, 이때 내보낸 이미지에는 러닝 시작·끝 위치와 Apple 지도에 표시되는 도로명·동네명이 포함될 수 있습니다.

개인 백업에는 신발 정보와 표시 순서, 러닝-신발 연결, 직접 작성한 메모, 월간·주간 마일리지 목표 설정과 Garmin 직접 연동으로 받은 운동 기록이 들어갈 수 있으며 Apple 건강 원본과 파생 분석 캐시는 포함되지 않습니다.

Firebase

Firebase Analytics와 Crashlytics는 식별자, 제품 상호 작용, 충돌·성능 정보, 기기·운영체제·앱 버전과 진단 메타데이터를 처리할 수 있습니다. Apple 건강 세부 정보, 경로, 심박 샘플, 메모, 신발, 위치·날씨 값과 사진은 Firebase 보고서에 첨부하지 않습니다.

사용자 제어

  • iOS 설정에서 Apple 건강 접근과 추적 권한을 변경할 수 있습니다.
  • 더보기 > 데이터 관리에서 제공되는 광고 동의 선택을 변경할 수 있습니다.
  • 더보기 > 데이터 관리 > 데이터 정리 및 초기화에서 신발·메모·목표 또는 분석 캐시를 초기화할 수 있습니다.
  • 개인 백업 파일을 내보내거나 가져올 수 있습니다.
  • 비공개 iCloud 개인 백업을 직접 생성·복원·삭제할 수 있습니다.
  • 더보기 > 데이터 관리 > 기록 가져오기 > Garmin에서 연결을 해제하고 받은 Garmin 기록을 유지하거나 삭제할 수 있습니다.
  • 앱 삭제 시 앱 내부 데이터도 제거됩니다. 별도로 만든 iCloud 백업은 앱의 삭제 기능으로 지울 수 있습니다.

플라이오버 동영상

플라이오버는 러닝 경로와 지표를 기기에서 무음 동영상으로 만들며, 저장을 선택하면 사진 앱에 추가합니다. 플라이오버 영상에는 시작과 끝을 포함한 전체 경로가 표시됩니다. 지도 표시와 영상 생성에는 Apple 지도 서비스에서 해당 지도 영역을 불러옵니다. 영상 생성 과정에서 입력 데이터나 완성 영상을 서버로 업로드하지 않습니다. 아래 Garmin 연동의 서버 전달은 별도이며, 운동 입력 데이터는 분석·크래시 보고·광고 서비스로 보내지 않습니다. 플라이오버 설정과 임시 영상은 개인 데이터 백업에 포함하지 않습니다.

Garmin 직접 연동

Garmin 직접 연동은 사용자가 선택하는 기능입니다. 사용하지 않아도 기존 Apple 건강 기반 기능을 그대로 이용할 수 있습니다. 별도 RunMoa 회원가입 없이 Garmin Connect의 연결 동의를 받으며, 앱은 연결용 익명 계정(Firebase Authentication)을 사용합니다. Garmin 비밀번호는 RunMoa가 받지 않습니다. 연결 전에 건강정보 처리 동의와 국외 처리 동의를 각각 받습니다.

Garmin 데이터 항목과 처리 목적

사용자가 Garmin Connect에서 공유에 동의한 범위에서 Garmin 사용자 식별자, 활동 식별자·종류·이름, 시작 시각, 시간·거리·칼로리, 페이스·속도, 심박·케이던스·고도·경로·랩·지원 센서 샘플, 기록 기기 정보 및 공유 권한을 처리합니다. 항목은 기기·운동·허용 권한에 따라 달라집니다. 연동 유지에 필요한 접근·갱신 토큰과 연결 상태도 처리합니다. 러닝이 아닌 활동은 내용을 보관하지 않고 수신 확인용 최소 표식만 남깁니다.

처리 목적은 사용자가 자신의 러닝 목록과 상세 정보를 보고, 거리·목표 진행률을 계산하며, 동일 운동의 중복 합산을 방지하고, 직접 선택한 공유 이미지와 경로 재생 영상을 만드는 것입니다. Garmin 연동을 위해 이름·이메일·일상 건강정보를 별도로 요청하지 않습니다.

Garmin 데이터는 Garmin에서 RunMoa가 통제하는 Google Firebase/Google Cloud 서버를 거쳐 iPhone에 전달됩니다. 서버는 운동을 암호화해 일시 보관합니다. Apple 건강에서 읽은 원본, 기기 내 분석 캐시, 기존 신발·메모·목표 백업을 Garmin 전달 서버로 업로드하지 않습니다.

Garmin 데이터의 보관과 파기

서버는 운동 전달을 위한 임시 보관에만 사용합니다. 앱이 운동을 기기에 저장했다는 확인을 보내면 해당 운동의 서버 원문·상세·요약을 지체 없이 삭제합니다. 앱이 받지 않은 운동도 최초 수신일부터 최대 30일까지만 보관하고 삭제합니다. 동일 알림의 재수신으로 보관 기한을 연장하지 않으며, 유효한 새 수정은 별도의 전달 기한을 갖습니다. 앱을 30일 넘게 열지 않으면 그동안 받지 못한 운동은 받을 수 없습니다.

Garmin 연결 식별자·권한·접근 및 갱신 토큰은 연결 유지에 필요한 기간 동안만 보관하고 연결 해제 시 삭제합니다. 기기에 내려받은 운동은 서버의 30일 보관 기간과 별개로 사용자가 삭제할 때까지 기기에 남습니다. 기기에 받은 Garmin 기록은 이 iPhone에만 저장하며 자동 iCloud/Finder 기기 백업에는 포함하지 않습니다. 사용자가 백업 및 복원에서 "지금 iCloud에 백업" 또는 "파일로 저장"을 직접 실행하면 Garmin 기록(경로·심박 포함 원본)이 함께 들어갑니다. iCloud 백업은 사용자 Apple 계정의 CloudKit 비공개 데이터베이스에 암호화된 파일로 저장되어 운영자는 접근할 수 없고, 앱의 iCloud 백업 관리에서 삭제할 수 있습니다. 백업 파일의 저장 위치와 공유·삭제는 사용자가 정하고 관리합니다. 복원하면 이 iPhone에 없는 Garmin 기록만 추가합니다(1.3.0부터).

서버를 운동 기록 복원용 백업으로 사용하지 않으며 운동 데이터의 별도 복원용 백업이나 장기 보관 사본을 만들지 않습니다. 앱 재설치 또는 새 기기에서는 Garmin을 다시 연결해야 합니다. 이전에 받은 기록은 사용자가 직접 만든 iCloud 개인 백업이나 백업 파일로 복원할 수 있으며, 백업이 없으면 복원할 수 없습니다. Garmin Starter 연결은 과거 기록 전체 조회를 제공하지 않습니다.

전달 확인용 최소 표식과 기술 로그는 운동 원문과 분리해 보관합니다. 일반 운영 로그 보관 기간은 30일입니다. 운동 원문·경로·심박 샘플·인증 코드·토큰은 로그에 남기지 않습니다. 개인정보 처리시스템의 관리자 접근 기록은 보안 목적으로 2년 보관하는 기준을 적용하며 마케팅에 사용하지 않습니다. Google 내부의 삭제·보안 감사 기록은 해당 서비스의 절차를 따르며 운동 복원용 백업이 아닙니다.

Garmin 운영 진단

연결과 전달 문제를 해결하기 위해 연결 단계·시각·허용된 오류 분류·연결 상태·앱 버전과 임시 진단 코드를 Google Cloud Logging에서 처리하며 보관 기간은 30일입니다. Google Cloud Monitoring에는 연결 수·예약 수·전송 대기·서버 사용량의 집계만 보내며, 진단 코드는 집계 항목에 쓰지 않습니다.

앱은 최근 기술 기록을 보호된 파일에 최대 80개 저장하고, 24시간이 지나면 다음 사용 시 진단 코드를 바꿉니다. 사용자가 문의 화면에서 복사를 선택한 경우에만 최대 20개 기록을 직접 공유할 수 있으며 자동 전송은 없습니다. 이 기록은 OS 자동 백업과 개인 백업에 포함하지 않습니다. 운동 원문·경로·심박·메모·신발·사진·토큰은 운영 진단에 넣지 않습니다.
